# kali_ms
Primeiro lab do bootcamp de Cybersecurity da Santander. 

Nesse primeiro lab, foram feitos ataques de força bruta nos sistemas ftp e smb de uma máquina Metaexploitable com a ferramenta Medusa. Eu utilizei também a ferramenta Hydra para encontrar o login da DVWA porque não encontrei muitas soluções na internet para os warning que o comando da Medusa estava retornando ao usar o módulo http.

Os arquivos usados estão todos na pasta "arquivos" e as imagens na pasta "imagens"
